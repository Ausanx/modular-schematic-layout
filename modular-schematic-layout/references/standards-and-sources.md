# 原理图标准与资料索引

本页只保存公开链接和适用范围提示，不复制标准正文。发布前核对出版社页面上的当前版本、修订状态、访问条件和项目合同要求。

- [IEC 61082-1:2014](https://webstore.iec.ch/en/publication/4469)：电工技术文件的编制规则背景，用于图纸组织、引用和表达习惯；不规定某个 EDA 的固定坐标。
- [IEC 60617](https://webstore.iec.ch/en/publication/2723)：图形符号数据库，用于确认符号语义和一致使用；具体库符号仍须核对目标工具。
- [IEC 61175-1:2015](https://webstore.iec.ch/en/publication/22490)：电工系统中信号指定的参考，用于命名和跨页识别；网络作用域及工具语法按工程设置确认。
- [IPC-2612:2010](https://www.ipc.org/TOC/IPC-2612.pdf)：电子设计与制造文件表达的参考；不替代项目图签、交付格式或受控文档要求。

## 使用边界

1. 这些资料帮助确定符号、命名和文件表达的依据，不把标准目录转换成固定模块框尺寸、字号、线宽或器件间距。
2. 原理图排版必须先保留已确认的连接、引脚、器件属性、极性和不同参考网络；视觉规则不能改变电气身份。
3. 标准页面或摘要不能证明网表、ERC、器件额定值、稳定性或 PCB 实现已经验证。只报告实际运行并查看的检查。
4. 当目标 EDA 的库、工程模板或项目规范更具体时，记录兼容性取舍并保持同一项目内的视觉语言。
