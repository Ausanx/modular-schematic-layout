# 测试说明

`evals.json` 包含五个可复用任务。交给待测 Agent 的输入为 `prompt` 和 `files`；文件路径相对于仓库根目录。`expected_output` 和 `expectations` 供结果审查使用，不作为任务提示。

| ID | 检查重点 | 输出 |
| --- | --- | --- |
| 1 | 异步 Buck 的主路径、反馈、地网保留 | 布局说明 |
| 2 | 从文字描述提出重排建议，承认缺少原生证据 | 审查意见 |
| 3 | 实际看图，区分连续导线、标签跳转与文字归属 | 审查意见 |
| 4 | 两通道 RC、缓冲与 AND 关系的实际绘图 | SVG、PNG、简短说明 |
| 5 | 功能分页、阅读密度与备注取舍 | 分页建议 |

## 运行与评价

1. 修改技能前保留旧版本，用独立上下文分别加载旧版与新版，执行相同任务。不让生成任务看到预期答案或另一版本输出。
2. ID 3 必须实际打开 `fixtures/labeled-paths.png`；SVG 是该合成图的可编辑源。A/B 中有名称的导线仍连续，C 的问题是长供电线和文字归属，D 才存在局部标签跳转。
3. ID 4 必须生成、渲染并查看图面。检查每个输入通道的完整路径、U1 单元和供电归属、文字锚点与导线交叉。不能以布局说明提到了要求就判定实际图面满足要求。
4. 自动检查适合判断文件存在、SVG 可解析、元件/引脚信息保留等事项。美观、阅读顺序、留白和细微遮挡仍需查看整页与局部。不用关键词命中率冒充视觉质量提升。
5. 记录每项判断的具体证据。旧版同样通过时如实记录；单次输出不代表稳定胜率。原生文件加载、网表等价、ERC 未实际执行就不报告通过。

## 数据边界

合成图样及抽象器件均为本仓库测试专用，不是真实芯片参考设计。图像审查用功能符号省略了部分供电脚，不能用它验证完整网表。真实项目的 PDF、审查原文、网表和截图不属于测试公开数据；公开反馈时请另行确认分享范围。

v0.2.0 增加了图像审查和实际 SVG 绘制的旧版/新版样例检查。ID 1/2 为既有文字测试，ID 5 为新增可复用分页任务；未因此宣称完成多轮统计基准或原生 EDA 工程验证。
