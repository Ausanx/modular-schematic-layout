# 测试说明

`evals.json` 包含八个可复用任务。交给待测 Agent 的输入为 `prompt` 和 `files`；文件路径相对于仓库根目录。`expected_output` 和 `expectations` 供结果审查使用，不作为任务提示。

| ID | 检查重点 | 输出 |
| --- | --- | --- |
| 1 | 异步 Buck 的主路径、反馈、地网保留 | 布局说明 |
| 2 | 从文字描述提出重排建议，承认缺少原生证据 | 审查意见 |
| 3 | 实际看图，区分连续导线、标签跳转与文字归属 | 审查意见 |
| 4 | 两通道 RC、缓冲与 AND 关系的实际绘图 | SVG、PNG、简短说明 |
| 5 | 功能分页、阅读密度与备注取舍 | 分页建议 |
| 6 | 无核心 IC、浮动/双向结构的跨页风格一致性 | 审查意见、项目样式 JSON |
| 7 | 不同图页任务、完整通道阵列、级联/共享控制、反序接口映射与信息层级 | 图纸组织方案、项目样式 JSON |
| 8 | 实际文字避让、位号/数值/规格的局部归属，保留固定图形与正常连接 | 修正 SVG、实际渲染 PNG、简短检查说明 |

## 运行与评价

1. 修改技能前保留旧版本，用独立上下文分别加载旧版与新版，执行相同任务。不让生成任务看到预期答案或另一版本输出。
2. ID 3 必须实际打开 `fixtures/labeled-paths.png`；SVG 是该合成图的可编辑源。A/B 中有名称的导线仍连续，C 的问题是长供电线和文字归属，D 才存在局部标签跳转。
3. ID 4 必须生成、渲染并查看图面。检查每个输入通道的完整路径、U1 单元和供电归属、文字锚点与导线交叉。不能以布局说明提到了要求就判定实际图面满足要求。
4. 自动检查适合判断文件存在、SVG 可解析、元件/引脚信息保留等事项。美观、阅读顺序、留白和细微遮挡仍需查看整页与局部。不用关键词命中率冒充视觉质量提升。
5. 记录每项判断的具体证据。旧版同样通过时如实记录；单次输出不代表稳定胜率。原生文件加载、网表等价、ERC 未实际执行就不报告通过。
6. ID 6 必须查看 `style-bridge.png` 与 `style-coupled.png`。两图刻意混用字体、颜色、线宽、框和标注习惯，属于待发现的样式问题，不是推荐风格。应统一视觉规则，保留不同的桥接与磁耦合拓扑；不因缺少芯片或 GND 要求新增器件或连接。
7. ID 7 是独立构造的文字方案任务，核对页面职责、真实针号与反序映射、不同网络、装配条件及导航方法。按实际方案证据判断，不把出现“统一”“层次”等词算作通过；此任务不能证明已完成重绘或多页视觉验收。
8. ID 8 必须查看 `annotation-collisions.svg` 与对应 PNG，只调整文字排版。对照 SVG 检查文字、字号、归属及非文字图形保留，再实际查看最终整页与关键局部，分别判断遮挡、裁切与字段漂移。导线落在引脚、结点位于导线等正常接触不应拆开；此任务不验证原生 EDA 或完整连接表。

## 数据边界

合成图样及抽象器件均为本仓库测试专用，不是真实芯片参考设计。图像审查用功能符号省略了部分供电脚，不能用它验证完整网表。真实项目的 PDF、审查原文、网表和截图不属于测试公开数据；公开反馈时请另行确认分享范围。

v0.2.0 增加了图像审查和实际 SVG 绘制的旧版/新版样例检查。ID 1/2 为既有文字测试，ID 5 为新增可复用分页任务；未因此宣称完成多轮统计基准或原生 EDA 工程验证。

v0.3.0 增加 ID 6，检查能否将原则迁移到不同结构，并建立项目级视觉规范。样式审查不能代替实际重绘后的跨页验收；有限样例也不能证明已经覆盖全部电路种类。

v0.4.0 增加 ID 7，检查多页工程是否按阅读任务选择表达方式，以及排版是否保留接口映射与装配信息。独立执行旧版/新版方案并比较具体证据；未由此宣称实际图面改善或统计优势。

v0.4.1 增加 ID 8，用固定图形的实际 SVG 排版任务检查文字互压、压住符号/导线和字段远离本体的问题。有限样例不能证明所有工具和工程都已消除遮挡；仍需检查每次实际导出。
