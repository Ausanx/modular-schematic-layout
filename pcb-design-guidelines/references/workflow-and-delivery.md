# PCB 工作流与同源交付

本参考文件把复杂整板任务中的通用执行纪律迁移为 PCB 施工指南和审查规则。具体线宽、叠层、阻抗、间距和工艺参数必须由项目输入、器件资料、计算及板厂能力确定。

## 任务模式与基线

先区分：

- **新板**：从需求、原理图/网表、封装和机械约束建立新工程。
- **现有板改版**：保留旧源、铜版、规则、制造状态和变更范围；先识别哪些板、层、网络、装配或固件受影响。
- **施工指南**：只输出可逐步执行的 CAD 操作、对象映射、约束、完成条件和未运行的检查。
- **审查**：按证据、风险、建议、依赖和实际检查结果报告，不凭截图声称已改板。
- **只更新 skill**：不启动 EDA、安装工具或修改生产工程。

建立输入基线：原理图/网表版本，`RefDes → 封装 → 关键引脚/网络`，板框/孔位/接口方向，层叠与板厂规则，装配/测试约束，以及 BOM/CPL/固件（适用时）的版本和哈希。每个参数标记为**已确认**、**计算初估**、**建议起点**或**待确认**。

## 工具能力与恢复

- 实际画板前分别确认 CAD 的原理图同步、PCB 读写、保存重开、规则、铺铜、DRC、网表/一致性和制造导出能力；工具握手或脚本成功不等于设计已保存或检查通过。
- 对陌生格式先在工作副本中小范围保存、重开、回读，再批量操作。原始工程和已冻结制造包只读保存；长任务记录当前板版、作业状态和已生成产物。超时/断线先检查已有输出，不重复创建或覆盖。
- 只在实际画板需要时检测和部署工具；技能更新、资料审查和方案编写不触发安装。缺少关键工具时继续输出可执行指南，并准确标出无法实际执行的步骤。

## 阶段出口

每个执行阶段写明“输入基线—退出判据—证据—未闭合项”：

1. **需求/机械**：板框、孔位、接口、禁布区、高度、隔离和制造条件闭合或已标阻断。
2. **同步/封装**：原理图、封装、引脚、极性和未连接项逐项核对。
3. **布局/回流**：关键电流闭环、参考面、接口保护、热路径和测试可达性可追踪。
4. **规则/布线**：层叠、线宽、间距、阻抗、时序、过孔和例外绑定到来源；具体规则未闭合时暂停对应签核，继续不依赖部分。
5. **验证/输出**：实际 DRC、连通性、网表一致性、Gerber/钻孔/装配输出和独立回读分别记录覆盖范围与结果。
6. **冻结/回归**：源、规则、叠层、库、BOM、CPL、模型和制造成员同源，改版只对受影响范围重新核验。

## 同源制造交付

完整板级交付（按用户范围裁剪）应能让另一位工程师在干净副本中继续打开和核对，通常包括：

- 原生原理图、PCB、项目设置、规则/叠层、项目库和必要模型；不能依赖设计机上的私人绝对路径。
- 与冻结源同源的 Gerber 或厂方接受的 ODB++/IPC-2581、钻孔/槽孔、BOM、CPL、装配图、DNP/后焊/选件和工艺说明。
- 版本、板身份、源/规则哈希和各检查报告；旧版成员若继承，说明字节/对象等价依据。
- 电脑验证与首板实测分开：DRC/DFM/计算通过不代表热、EMC、阻抗、功能或可靠性已由实物证明。首板步骤应覆盖来料/焊接、断电、限流上电、各电源、下载/复位、接口和受影响回归。

任何铜、焊盘、孔、板框或规则改变都要重新导出受影响制造成员并复查；不能只改文件名或 BOM 文字冒充新铜版。BOM、CPL、原生应装位号和 DNP 清单分别对账。

## 审查/施工指南格式

对每一条重要建议尽量写成：

`RefDes/网络 → PCB 对象与起终点 → 层/参考 → 约束值及来源/状态 → CAD 操作 → 完成检查`

缺少 CAD 时给用户可逐条执行的 UI/人工步骤，不声称已编辑。最终答复先给有效文件和结论范围，再列实际检查、待确认项和恢复入口。
