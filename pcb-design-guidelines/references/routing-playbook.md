# PCB 走线作业剧本

本页用于把“布线按什么顺序、从哪里走到哪里、什么时候停下来检查”写成可执行清单。它不替代原理图、器件数据手册、层叠、板厂规则或产品标准；具体线宽、阻抗、间距、过孔和长度必须绑定到项目输入。没有原生 CAD 时，本页只能生成施工指南，不能声称已经完成走线或通过 DRC。

## 先画路线图，不先画线

对每条重要网络建立一行记录：

`网络/器件 → 起点焊盘 → 终点焊盘 → 允许层/参考平面 → 走线类别 → 约束来源/状态 → 过孔与回流方案 → 完成检查`

按下面的顺序确定优先级：

1. **机械和隔离边界**：板框、安装孔、连接器配接方向、禁布区、高度、爬电/电气间隙。
2. **高 $di/dt$ 闭环和大电流路径**：从实际开关状态画出正向路径与相邻回流，先锁定器件邻接和允许层。
3. **电源分配与地回流**：输入、输出、负载和局部去耦，检查压降、颈缩、过孔和热扩散。
4. **受控阻抗、时钟和差分网络**：先确认层叠和参考平面，再按端点和拓扑布线。
5. **敏感模拟、反馈、采样和复位**：从安静取样点到引脚，避开开关节点和快速边沿。
6. **接口保护、一般数字和低速控制**：保护器件靠近连接器，最后处理低风险支路。

每完成一个优先级，先检查关键回路和回流，再进入下一级。不要先用自动布线把所有网络铺满后再试图修复电源或高速路径。

## 各类网络怎么走

### 功率和高 $di/dt$ 回路

- 从原理图的开通、关断状态分别追踪换流回路；不能只依据网络名或芯片引脚顺序套用 Buck/Boost 模板。
- 将输入旁路/储能电容、开关器件、续流/整流器件和对应地回流放在同一物理邻域；正向路径和回流路径靠近、短、宽、连续。
- 先布闭环，再布闭环的输入/输出连接。对需要换层的段，先确认相邻参考平面和回流过渡，再决定过孔位置；少过孔本身不是目标。
- 开关节点只保留完成拓扑所需的最短铜段，远离 FB、补偿、晶振、ADC 输入和连接器敏感线；不要为了“看起来直”扩大开关铜区。
- 大电流路径按持续/峰值电流、脉冲占空比、铜厚、内外层、允许温升、压降和板厂能力分别计算；过孔阵列按孔径、筒壁铜厚、数量和均流验证。

### 电源转换的拓扑检查点

以下是检查方法，不是可脱离实际原理图复制的固定连线：

| 拓扑/对象 | 先锁定的物理关系 | 走线时重点检查 |
| --- | --- | --- |
| Buck | 输入电容与开关/续流支路及其输入回流形成最小换流环；开关节点到电感；电感到输出电容/负载 | 输入环是否闭合且短；SW 铜段是否受控；输出电容回流是否直接；FB 是否从安静输出点取样并避开 SW |
| Boost | 输入电容、储能电感、开关器件和输入回流的换流环；电感/整流器件到输出电容的能量路径 | SW 节点面积和耦合；整流器件到输出电容的路径；输入与输出回流是否被错误共用 |
| 反相/电荷泵 | 按每个开关相位标出电容充放电闭环和极性 | 飞跨电容引脚顺序、开关节点面积、回流过孔和极性标记 |
| LDO | 输入旁路电容—VIN/PGND，VOUT—输出电容—回流的局部闭环 | 电容到引脚的总回路长度；高阻反馈点；功耗和散热铜路径 |
| 驱动器/电机/H 桥 | 电源去耦—功率开关—负载—回流的开关电流路径；栅极驱动局部回路 | 栅极回路短且有明确参考；功率回流不穿过逻辑/采样区；续流和浪涌路径可追踪 |

### 反馈、采样和模拟信号

- FB/COMP/电流采样从真正的安静取样点引出；需要精度时采用 Kelvin 取样，并在指南中写出取样焊盘和回流焊盘。
- 反馈线与 SW、栅极驱动、时钟、大电流铜和连接器边缘保持项目约束要求的间距；不要用标签名称代替实际参考路径。
- 模拟链按“源/连接器 → 保护 → 滤波 → 放大/ADC”顺序布置和走线；信号回流与对应参考面连续，避免跨越开关回路或平面裂缝。
- 高阻节点尽量短，必要时设置保护环/屏蔽铜，但只有在原理图、器件资料和回流分析支持时才加入。

### 差分、时钟和受控阻抗网络

- 先从发送端到接收端确定拓扑、端接、允许层、参考平面、目标阻抗、长度/偏斜和过孔结构；这些值必须来自接口约束、器件资料、仿真或板厂叠层。
- 差分成员保持同层、同参考、连续耦合和相同过孔结构；只有为满足拓扑或器件引脚才换层。不要为了视觉平行擅自交换 P/N 或添加无依据蛇形。
- 时钟和快速单端线保持连续参考、少分支、少 stub；换层时在信号过渡附近提供合法的回流过渡结构。
- 线宽/间距未由实际叠层求解前，只能标为待确认；数据率或时钟频率不能直接生成制造线宽。

### 接口、保护和一般控制线

- ESD/浪涌保护器件放在连接器到板内核心的第一入口处；放电回流直接到指定机壳地/保护地/回流入口，不能穿过敏感核心。
- 连接器信号按真实端点走向核心器件；复位、使能、I2C/SPI、GPIO 等低速线最后布，跨模块处才使用标签或端口表达长距离连接。
- 一般控制线避免穿过高 $di/dt$ 区和模拟采样区；若必须跨越，写明参考层、回流路径和隔离理由。

## 换层与回流的逐条动作

每次准备放置过孔时按以下顺序执行：

1. 记录信号从哪一层切到哪一层、切换前后的参考平面和允许的阻抗/长度变化。
2. 检查相邻参考平面是否连续，是否有分割、孔洞、反焊盘或连接器边界导致回流绕行。
3. 为回流安排就近且合法的过渡（例如相邻参考层之间的回流过孔或明确的平面连接），并检查其与隔离边界的关系。
4. 核对过孔的成品孔、焊盘、环宽、阻焊和板厂能力；高速网络还要检查 stub、反焊盘和阻抗变化。
5. 重新检查换层前后走线长度、差分偏斜、功率压降、热瓶颈和 DRC 规则例外。

## 走线几何与完成判据

- 采用 CAD 支持的 45° 转角或圆弧，避免尖角、无意义的回折、狭窄颈缩和穿过焊盘/禁布区；几何偏好不能覆盖电气或机械约束。
- 走线必须从真实焊盘/过孔到真实焊盘/过孔闭合；网络标签、颜色、飞线消失或视觉平行都不算完成。
- 每条关键网络完成后，至少核对：起终点正确、层和参考正确、回流连续、过孔方案可制造、宽度/间距/阻抗/长度有来源、没有未解释的规则例外。
- 铺铜后重新填充并检查孤岛、窄颈、热焊盘、回流路径和隔离；铺铜不能掩盖错误走线。
- 只有实际运行并查看 DRC、网表/连通性、阻抗/时序、热/载流或制造输出检查后，才能把相应项目写成“通过”。

## 施工指南中的最小示例格式

```text
网络：VIN_PROT → U1.VIN
对象：CIN1.1、U1.VIN、CIN1.2/PGND
路径：先将 CIN1 放在 U1.VIN 与输入开关支路旁；VIN_PROT 从接口/保护件到 CIN1.1，再到 U1.VIN；CIN1.2 以最短回流连接到 U1 的功率地参考。
层/参考：外层短路径；回流参考为连续 PGND 平面（待叠层确认）。
约束：线宽由电流、压降、铜厚和板厂能力计算；状态=计算初估/待确认。
完成检查：起终点与网表一致；换流环闭合；没有长颈缩或跨越 FB/SW 敏感区；实际 DRC 待执行。
```

这个格式应套用于每条关键电源、差分、时钟、反馈、接口保护和测试网络；普通低速网络可以合并成网络组，但仍需给出起点、终点和参考层。
