# PCB 参数与计算方法

本页将参数分成**电气/安全要求**、**计算初估**与**制造能力**。具体值必须对上项目网络、层叠、器件及供应商；下列公式和示例不是通用设计表，也不证明 IPC、法规或产品标准符合性。来源与查证范围见 [标准与资料索引](standards-and-sources.md)。

## 线宽：温升、压降和制造能力分别检查

逐段列出工作/峰值电流、持续时间/占空比、外层或内层、成品铜厚、允许温升、线段长度、允许压降及板厂蚀刻/线宽能力。避免将一个网络的“最大电流”未经分析地套给所有支路。

IPC-2152 是载流能力的专用标准参考；设计者需结合其热环境、导体位置、铜平面、板材和实际工作条件使用。不要引用未读取的标准全文或把标准曲线简化成无条件的固定表。KiCad PCB Calculator 的 Track Width 工具明确基于较早的 IPC-2221 经验关系。附带脚本复现该计算器源码中的经验式，供透明的**初筛估算**：

$$I = k\,\Delta T^{0.44} A^{0.725}$$

其中 $I$ 为 A，$\Delta T$ 为 °C，$A$ 为铜截面积 mil$^2$；外层 $k=0.048$、内层 $k=0.024$。若铜厚 $t$ 用 mil，则：

$$A = w_{mil}t_{mil}, \qquad w_{thermal}=\frac{1}{t_{mil}}\left(\frac{I}{k\,\Delta T^{0.44}}\right)^{1/0.725}$$

矩形导体的直流压降可独立估算：

$$R=\rho\frac{L}{wt},\qquad \Delta V=IR,\qquad P=I^2R$$

其中 $L,w,t$ 使用一致的 SI 单位。20 °C 时铜电阻率初估可取 $\rho=1.72\times10^{-8}\ \Omega\cdot m$；导体升温后电阻增加。给定最大压降 $\Delta V_{max}$ 时：

$$w_{drop}=\frac{\rho L I}{t\Delta V_{max}}$$

把各约束换算到同一单位后，所选**最小成品轨宽**至少应覆盖 $\max(w_{thermal},w_{drop},w_{fab,min})$，再按板厂工艺公差、设计余量和 CAD 可用网格向上选定可制造值。热初估与压降初估任何一项缺输入就明确标为待确认。确认电流、电压降、铜厚、层和温升后运行：

```text
python "<pcb-design-guidelines skill directory>/scripts/trace_width.py" --current-a 1 --copper-um 35 --layer external --delta-t-c 10 --length-mm 50 --max-drop-mv 50 --fab-min-mm 0.15
```

将路径占位符替换为当前已安装的 `pcb-design-guidelines` 目录；从本机 Agent skills 目录或当前项目安装目录中查找，不依赖用户项目的工作目录。

脚本只处理均匀矩形铜线、稳态电流和 20 °C 电阻率；不建模脉冲热响应、温度系数、蚀刻轮廓、焊盘扩散、铜平面、相邻导体热耦合、过孔、颈缩、交流集肤/邻近效应或电流拥挤。对这些场景使用 IPC-2152 适用方法、实测/热模型、板厂建议或专业工具。

**算例（仅演示计算，不是推荐线宽表）**：外层、铜厚 35 µm、1 A、允许温升 10 °C，旧经验式给出热初估约 0.300 mm。若该均匀直线长 50 mm 且压降上限 50 mV，20 °C 直流模型要求约 0.491 mm；再按实际制造能力向上选规格并验证温升和电流波形。可见只算温升会低估所需宽度。

对内层平面、过孔阵列、多层并联分流、脉冲/浪涌或高环境温度，不能把单条外层公式照搬。过孔载流需使用过孔筒壁铜厚、成品孔径、长度、数量/均流和热环境；向板厂核对可制造孔径及电镀能力，并结合 KiCad Via Size 计算器或热/电场工具，不套固定“每个过孔承载几安”的表。

## 间距、隔离和板厂能力

- **制造最小间距**：取实际板厂、铜厚、层数、蚀刻方式和公差表中对应条件；板厂“极限能力”不等于设计推荐值。将设计值留出能力余量。
- **电气间隙/爬电距离**：按产品标准、工作电压/瞬态、污染等级、材料组别、海拔、涂覆/槽孔规则及适用类别确定。制造最小间距只说明能否加工，不能代替安规距离。必要输入不足时可完成普通低压布局，但相关高压间距和签核状态必须阻断放行。
- **线路/铜到板边、阻焊桥、丝印到焊盘和环宽**：分别使用目标板厂对应的板厚、层数、工艺能力和器件焊接要求；注意成品孔径与钻头尺寸不是同一参数。
- 建立规则时同时记录网络、来源、目标值和硬性下限。若 CAD 的网络类别只提供默认宽度，增加能报告违规的 DRC 规则并用故意违例样例确认规则确实生效。

## 阻抗、时序和差分对

- 先确认信号边沿/接口约束、层叠材料及介质厚度、走线层与参考平面、铜厚、阻焊、线宽/间距、过孔和板厂阻抗公差。比特率或时钟频率本身不能直接给出线宽、端接、长度或偏斜。
- 由实际层叠求出单端/差分阻抗候选；优先与板厂讨论其场求解器、阻抗 coupon、成品公差和可制造尺寸。KiCad 传输线工具适合初估截面，不替代板厂最终叠层和受控阻抗确认。
- 约束来源应是适用接口标准、发送/接收器件数据手册、拓扑/仿真和板厂能力。对差分阻抗、层/参考平面、匹配长度/偏差、拓扑和允许过孔分别记值；不要仅按几何规则对齐两根线。
- 阻抗或长度尚未确定时可以完成机械、分区和不冲突的摆放，但标记受控网络及其禁止签核的布线阶段；不要猜成品线宽。

## 过孔、封装、热和可读性

- 过孔规则需分别写名义钻孔/成品孔径、焊盘、环宽、通孔/盲埋结构、层对和板厂公差；确认 CAD 单位及孔径语义。
- 焊盘形状尺寸优先来自器件厂商机械图与安装要求，再依据已选择的 land-pattern 方法和装配工艺验证；IPC-7351 提供方法，不自动确定每个器件的唯一焊盘尺寸。
- 热分析需有器件损耗/功耗、热阻、铜面和过孔、板材、环境、气流/安装条件。没有这些输入，只画出散热路径与待验证项，不给虚假精确温升。
- 丝印文字高度/线宽和铜、阻焊、板边退让以板厂与装配厂能力为准；所有 RefDes/值/极性标记要靠近对应封装且不遮住焊盘、开口、测试点或其他文字。渲染并逐页/逐面检查，而非只看 CAD 选择框。
