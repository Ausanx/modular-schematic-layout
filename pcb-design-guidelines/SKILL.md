# PCB Design Guidelines

通过真实的电流、信号回流、机械边界和制造约束组织 PCB。布局目标是让关键物理关系可追踪、风险可验证，而不是让所有器件形成整齐阵列或套用一个项目的尺寸。

## 适用边界

- 用于 PCB 规划、分区、器件布局、布线优先级、叠层/参考平面、阻抗、热、隔离、装配、测试和 DFM 审查。
- 输入可以是原理图/网表、封装与机械约束、层叠表、约束表、CAD 导出、渲染图或截图。优先使用可查询的原生数据；只有图片时只报告可见证据。
- 以用户确认的连接、封装、极性、机械边界和器件资料为基线。不得因为外观、对称或短线而换引脚、改网络、改变极性、删除器件或跨越隔离边界。
- 用户要求可执行设计指南时，执行完成该指南所必需且输入充分的线宽压降、阻抗或规则计算；说明模型、输入、结果和适用边界。没有必要输入时不伪造数值，也不把计算初估称为标准符合性、仿真或认证。
- 原理图 skill 解决图纸表达；本 skill 解决板级物理实现。原理图上的邻近关系不等于 PCB 上满足去耦距离、回流、热或安规间距。

## 先识别交付模式

- 用户给出原理图/网表并要求“怎么画、完整步骤、照着做”等：进入**施工指南模式**。提取器件—封装—网络—接口关系，产出按顺序可执行的设置、摆放、规则、布线、铺铜和验收步骤；不要只给原则性审查意见。读取 [references/from-schematic-to-board-guide.md](references/from-schematic-to-board-guide.md)。
- 用户要求检查已有板图：进入**审查模式**，按证据、风险和修复优先级报告。
- 两类输入同时存在时，先审查会改变施工顺序的阻断项，再交付可继续执行的步骤。
- 每个具体参数标记为**已确认**、**计算初估**、**建议起点**或**待确认**，并给来源/假设。缺少参数时，只暂停依赖该参数的签核或布线规则；继续完成不依赖它的板框、器件分区、关键邻接、候选走线顺序和资料收集。

在正式移动器件或写入规则前，建立项目的原理图/网表、封装、机械、层叠、板厂、装配和测试基线；改版还要记录旧板版、制造状态、规则/源哈希和变更范围。工具握手、脚本成功、文件存在、保存重开、DRC/连通性实际执行和制造输出回读是不同证据。完整模式选择、恢复流程、同源冻结和交付成员见 [PCB 工作流与同源交付](references/workflow-and-delivery.md)。

- 只更新本 skill、资料审查或方案编写时，不启动 EDA、安装软件或修改生产工程。
- 对陌生 CAD/格式先在工作副本做小范围写入—保存—独立重开—回读；超时或断线先检查已有产物，避免重复创建或覆盖。
- 缺少关键输入时，只阻塞受影响的线宽、阻抗、隔离、制造或签核结论；板框、器件分区、关键邻接、资料请求和不依赖部分的施工步骤继续推进。

## 1. 先收集约束，再决定优先级

在移动器件或画线前整理一个约束表，至少检查：

| 约束组 | 需要确认的内容 |
| --- | --- |
| 机械 | 板框、安装孔、禁布区、外壳、连接器配接方向、高度和散热器 |
| 工艺 | 层数、材料、铜厚、最小线宽/间距、孔径、阻焊、表面处理、板厂能力、拼板和装配工艺 |
| 电气 | 关键网络、工作电流、额定/瞬态电压、阻抗、时序、噪声敏感度、隔离等级和参考平面 |
| 热与可靠性 | 热源、环境、允许温升、散热路径、寿命、污染、爬电/电气间隙和产品标准 |
| 组装与测试 | 贴装方向、可视性、返修、测试点、探针方向、调试接口、DNP/选件和序列化需求 |
| 工具与交付 | CAD 工具/版本、规则文件、原理图网表、封装来源、Gerber/ODB++/IPC-2581 需求 |

优先级按影响而不是视觉整齐度排序：固定机械约束和隔离边界 → 高 di/dt 功率回路与其回流 → 连接器和关键接口 → 时钟/高速与敏感模拟 → 一般信号与低风险支路 → 文字、阵列和装饰。若用户给定的优先级不同，记录原因并服从明确约束。

施工指南须把原理图对象映射为可操作条目：`网络/器件 → PCB 对象 → 起点与终点 → 层/参考 → 约束值及来源 → 操作 → 完成检查`。不能仅写“走线尽量短”“电容靠近芯片”或“设置合适线宽”。缺少 CAD 文件时给可执行的 UI/人工步骤，不声称已修改板或运行检查。

## 2. 分区和器件布局

- 按能量转换、数字控制、模拟采集、接口/保护、隔离侧和测试维护等真实职责分区。分区是电气和机械边界的表达，不等于强制画成相同大小的矩形。
- 先放板框、安装孔、固定件、连接器和必须靠近外部接口的器件，再放每个功能单元中的关键器件，最后放一般无源件。保留配接方向和维修可达性。
- 功率级按实际能量路径摆放输入旁路、开关器件、储能/续流器件和输出滤波；缩小高 di/dt 回路的闭合面积。不要只按参考标号、封装种类或自动排列。
- 去耦电容靠近对应供电脚和连续的回流过孔/平面，先确认电源单元归属；共享电源不能掩盖局部去耦缺失。高频旁路、储能和 bulk 电容按其作用和电流路径分层处理。
- 模拟前端和高阻节点远离开关节点、时钟、快速边沿和大电流回路；让传感器、连接器、保护件和放大/转换器保持真实信号顺序。不要用“模拟区”标签代替回流路径设计。
- 重复通道可以规则阵列，但重复的是完整功能单元、方向、测试与去耦归属；不同供电域、特殊通道和边界条件要显式保留。
- 预留布线通道、铜皮扩展、热扩散和测试探针空间。避免为了填满板面而把低优先级器件塞入关键回路或禁布区。

## 3. 关键电流路径与回流

- 先追踪实际电流闭环，再选择层和线。对开关电源，应按具体拓扑、器件和开关状态追踪开通/关断期间的高 di/dt 换流回路、能量传输路径与控制/反馈参考回路；Buck 的输入电容—开关支路—续流支路—输入电容只是一个常见例子，不把同一回路模板硬套到 Boost、反激或其他拓扑。对驱动器、马达、继电器和大电流接口同样追踪开通与关断路径。
- 高 di/dt 导线应短、宽、连续，正向路径与回流路径相互靠近；不要把回流强迫绕过分割平面、过多过孔或无关区域。具体宽度和过孔数量由电流、铜厚、层叠、温升和板厂能力决定。
- 参考平面保持连续。高速或敏感信号跨越参考平面切换、分割、孔洞或连接器边界时，说明回流如何转移，并在需要处提供合法的过渡与回流结构；不能只看信号线长度。
- 差分对保持规定的耦合、长度、阻抗和参考关系；不要为视觉平行而改变已确认的极性、交换成员或制造不必要的蛇形。
- 保护器件靠近受保护接口和实际回流入口；ESD/浪涌电流路径不应穿过敏感核心。隔离电源/信号两侧保持边界，不通过铜皮、过孔或安装件偷偷跨接。
- 地平面、机壳地、模拟地、功率地是否分割或单点连接取决于真实电路、回流和产品约束。不要把“整面铺地”或“必须分地”当成普遍答案。

## 4. 层叠、阻抗与布线顺序

1. 根据接口速率、阻抗、回流、层数、铜厚、材料和板厂能力制定叠层候选；记录介质厚度、参考层、铜厚和阻抗目标的来源。
2. 为关键网络指定允许层、参考平面、线宽/间距、过孔结构、长度/偏差、差分耦合和拓扑。阻抗目标不能脱离实际叠层和制造公差。
3. 先布高 di/dt 电源回路、时钟/高速差分、敏感模拟和关键控制，再布一般信号和低速网络。每个优先级都要保留可连续的回流路径。
4. 需要换层时，让回流有可用的相邻过渡；过孔、反焊盘、平面开口和连接器区域按实际结构检查。避免把“少过孔”作为脱离回流的独立目标。
5. 铺铜前确认网络、热连接、隔离、平面分割和未连接铜处理。铺铜不是修复错误回流的遮罩；在最终层叠和规则下重新检查孤岛、窄颈和热路径。

线宽、间距、过孔、阻抗和时序约束的计算选择见 [references/pcb-parameters-and-calculations.md](references/pcb-parameters-and-calculations.md)。对于已知电流、铜厚和温升等条件，可运行此 skill 目录下的 `scripts/trace_width.py` 同时估算热约束和直流压降约束；该脚本只作矩形铜线初估。

## 5. 热、载流、隔离与可靠性

- 识别器件损耗、热源耦合、铜箔扩散、过孔阵列、散热焊盘、外壳/散热器和气流的完整路径。没有功耗、环境或材料数据时，不给出看似精确的温升结论。
- 载流能力根据导体截面、内/外层、铜厚、环境和允许温升计算或查适用数据；不要把某个“10 mil 可承载 X A”的经验推广到所有板。
- 爬电距离、电气间隙、槽孔、阻焊和隔离带按适用产品标准、工作电压、污染等级、海拔、材料组别和板厂能力确定。未确认这些输入时只标出需要核实的边界。
- 高压、隔离、机壳和接地连接考虑装配公差、螺钉/屏蔽件、测试夹具、污染和返修；机械开口不能只在 CAD 顶视图上看起来分开。
- 热焊盘、过孔和铜皮同时满足焊接、回流、散热和可返修要求；不要为了热扩散堵住焊膏开窗或让器件无法贴装。

## 6. 可制造性、装配与测试

- 逐项核对板厂最小线宽/间距、孔径/环宽、阻焊桥、铜到板边、槽孔、盲埋孔、表面处理、阻抗公差、拼板和检测能力；规则文件要与真实供应商能力一致。
- 封装焊盘以器件厂商机械图、选定 IPC land-pattern 方法和实际库验证为准。检查极性标记、Pin 1、焊盘编号、热焊盘、阻焊开窗和装配方向。
- 保留贴装、返修、探针和视觉检查空间；测试点要连到真正需要测量的网络并可从允许的面接触。不要为了“每网一个测试点”牺牲隔离或高速回流。
- DNP、互斥选件、跳线默认状态、可替代料和序列化信息应能从装配数据追到 PCB 对象；不要仅靠颜色或丝印表达关键安全信息。
- 输出前检查原理图—PCB 网表/连接、封装映射、未连接项、规则例外、丝印重叠、板框、钻孔、铜皮和制造文件。只有实际运行并查看工具输出，才可报告 DRC/DFM 通过。

## 7. 审查交付格式

先给结论范围，再按优先级列出：

1. **证据**：页码/坐标/网络/层/对象和能看见的具体关系。
2. **风险**：电流回路、回流、串扰、热、隔离、装配或制造后果。
3. **建议**：最小且可操作的摆放、层、线、过孔或规则调整。
4. **依赖**：必须从数据手册、叠层、板厂、产品标准或用户确认得到的输入。
5. **已执行检查**：实际打开的文件、运行的规则/计算和结果；未执行的检查列为建议，不写成通过。

修图或生成 CAD/SVG 时，保留用户的连接、封装和机械对象；同时检查文字、丝印、标记、板框和图形之间的遮挡、裁切与归属。视觉整齐是可读性指标，不是电气或制造证明。

施工指南交付格式和各阶段的停止/继续条件见 [references/from-schematic-to-board-guide.md](references/from-schematic-to-board-guide.md)。

## 7.1 同源冻结与首板边界

- 完整板级交付应从同一冻结源生成原理图、PCB、规则/叠层、Gerber 或厂方等效制造数据、钻孔、BOM、CPL、装配图及适用模型；依赖私人绝对路径的工程不能标为可继续交付。
- 源、制造数据、装配成员、固件（如适用）和检查报告绑定板身份、版本与哈希。铜、焊盘、孔、板框或规则改变后，重新导出受影响成员并复查；不能只改文件名或 BOM 文字冒充新铜版。
- DRC、DFM、载流/阻抗计算和仿真只证明各自实际覆盖范围。首板实测、EMC、热、功能、可靠性和认证单独列为未测或已测，不用电脑结果替代实物证据。
- 改版交付列出旧版基线、变更对象、受影响检查、可继承证据和仍待复核项；BOM、CPL、原生应装位号与 DNP/后焊清单分别对账。

## 8. 常见错误

- 先按器件类别排成矩阵，再试图用长线补救功率和信号路径。
- 只优化信号线长度，不检查高速信号的参考平面和返回路径。
- 把“整面地”“星形地”“全部分地”“尽量少过孔”作为无条件规则。
- 直接复制厂商评估板坐标，却没有核对不同封装、层叠、散热、接口和机械边界。
- 把原理图标签、铺铜颜色或丝印文字当作真实网络、隔离或 DRC 证据。
- 未确认板厂能力就给出固定线宽、间距、孔径、阻抗或爬电数值。
