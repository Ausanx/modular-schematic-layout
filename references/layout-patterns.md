# 按功能关系推导布局

此文件用于把通用原则落实为图面结构。分类依据是连接关系和功能角色，不是器件型号。示例不构成穷举清单，也不是默认电路；未提供的器件、引脚、参考端和电气关系都不能自行添加。

## 1. 主路径与局部分支

- 找出读者理解该功能时首先需要追踪的路径，把路径中的节点和器件按实际顺序摆出，再在对应节点旁展开支路。
- 串联器件顺着路径，旁接器件垂直或成组展开；辅助器件的位置由其作用对象决定。同类通道复用这种关系，而不是按位号顺序排队。
- 路径不一定经过芯片。纯无源网络、分立电路、连接器适配或保护网络同样可以是完整功能区。
- 当路径较短时，连续实线通常比两个同名标签更容易读；共享资源和跨模块关系则可用统一端口表达。

## 2. 回路、取样与反馈

- 区分前向路径、返回路径和支路，让闭环或取样关系在图面上可追踪。不要为了单向阅读把返回线割成标签岛。
- 将取样、设定或补偿网络放在作用节点附近；文字命名附着在连续导线上不会打断拓扑。
- 导通回路、电源回流与控制反馈具有不同含义，按实际连接表现，不把它们画成同一个回路或自行接地。
- 为返回路径预留独立走线通道，避免穿越器件本体和无关引脚；必要时调整器件组的位置，不靠长线绕整页。

## 3. 成对、平衡、桥接与耦合

- 成对信号保持相邻、对应节点对齐；有意义的对称帮助比较，元件值或连接不对称时按原样保留，不为外观强制对称。
- 桥接和多支路网络围绕其关键节点组织，显露臂与中点的关系；无需压成单一的左到右链。
- 双向传输可以用两侧对等端口表达。没有明确输入输出角色时不伪造方向；差分两端也不自动成为电源与地。
- 耦合器件保持对应关系与真实耦合标识；隔离两侧既能看出所属功能，又保留边界和不同参考网络。视觉距离不是安规间距的证明。

## 4. 多端口、扇出与共享资源

- 对多端口器件，按功能或接口成组组织引脚及周边，先保证每个局部关系可读。芯片的物理封装顺序不必决定整页的布局顺序。
- 共享控制、供电或总线放在归属明确的位置，通过短支路、实际电源单元、合法总线或端口分配；不要求将所有共享连接拉成长线。
- 可用功能/多单元符号时保留位号、引脚电气类型、单元及封装映射。库不支持时，用功能分组和端点标注改善阅读，不虚构符号。
- 扇出较多时，平行走线分组并保留间距，标签命名和端口位置遵循项目规范。实线与端口的取舍依据阅读负担，不按同框直连百分比决定。

## 5. 重复、层次与尺度

- 同类通道使用同样的器件顺序、相对朝向、文字锚点和间距；不同功能可以采用不同拓扑形状，仍共用字体、线条、端口和图框语言。
- 用组内邻近、组间留白、模块框和分页形成由小到大的层级。不要为每个器件或小支路单独画框，也不要为整齐给不同功能强行相同大小的框。
- 按功能完整性和最终阅读比例安排分页。大型接口或独立子系统可以有专页；简单功能也可以与相关模块同页。已有层次改变须在用户授权范围内。
- 对不同页幅保持可比的文字与线条阅读尺度；过密时调整布局，不用某一页的微小字体掩盖问题。

## 6. 原则应用示例

| 电路结构示例 | 应用的通用关系 | 画法重点 |
| --- | --- | --- |
| 功率转换 | 前向能量路径、开关支路、取样返回 | 连续显示已有功率与反馈拓扑，不增添模板器件 |
| 执行器驱动 | 主支路、控制支路、已有续流路径 | 展示共同节点及回路，不把局部并联关系拆成标签岛 |
| 信号调理或检测 | 串联通路、旁接支路、取样作用端 | 相邻阶段可追踪，支路靠近所属节点 |
| 状态或组合逻辑 | 依赖链、共享控制、多单元归属 | 表达实际功能关系，电源及未用单元有明确处理 |
| 平衡网络或磁耦合接口 | 成对、桥接、双向或隔离关系 | 保留配对与边界，不强制中心 IC、单向链或 GND |
| 供电与去耦 | 共享资源、局部支路、所属器件 | 正电源对地电容通常竖放，短供电线、正确参考符号；负电源和非地支路按真实极性处理 |

对未列举的电路，先回答：哪些节点共同决定一个功能？哪些关系必须在局部看见？哪些连接适合跨边界表达？据此选择结构，再套用项目统一的视觉规范，无需追加一个器件专属模板。
