# 图纸组织与导航

用于多页工程、大规模重复结构和高引脚数接口。目标是让读者先找到功能，再理解局部关系，最后能查到实际端点；不规定固定页数、每页器件数或统一模块尺寸。小设计可在一页完成这些任务。

## 1. 让图页承担清楚的阅读任务

| 阅读任务 | 需要呈现的信息 | 合适的表达 |
| --- | --- | --- |
| 理解系统 | 子系统关系、主要信号/能量方向、共享控制和供电来源 | 已有层次块、合法总线、少量关键连线及清楚的页名/接口 |
| 理解局部功能 | 器件、支路、采样、反馈、耦合与参考关系 | 真实器件符号、连续局部实线、就近辅助网络 |
| 查线与配接 | 针号、网络、Bank/通道范围、供电域、目的位置及已知视图 | 有序引脚短线与标签、明确分组、必要的映射表或引用 |

- 同一视觉规范贯穿这些表达，但允许不同的信息密度。不要要求总览展开全部器件，也不要用总览方块代替需要交付的电路实现。
- 真实层次页符号具有电气接口；图形注释框只有视觉边界。制作另附架构图时标明其用途，避免向原生工程重复放入器件或建立第二套连接。
- 先复用已有页序和层次。在授权范围内改善标题与相邻页关系；新增总览或合并页面须有阅读收益，不以模板规定为理由扩张工程。

## 2. 用重复单元建立秩序

- 先完成一个有代表性的完整单元，再按行列复用其内部拓扑、引脚短线、标注锚点和间距。这里重复的是功能，不是把所有同类元件从各单元中抽出来排队。
- 用短标题标明每组真实的通道/成员范围；同一阅读顺序贯穿页内和页间。保留非连续或反序的真实映射，通过分组或映射说明降低查找成本，不靠重编号制造顺序。
- 同类单元的不同值、供电、默认状态或选件应明确可见。统一外观不可掩盖功能差异，也不能用“其余相同”省略原生元件与连接。
- 相邻级联关系保留为线；共享时钟、控制与独立扇出按组使用端口或标签。若一条级联需换行，清楚标出行尾和下一行的对应端点，不让视觉行序暗示错误电气顺序。
- 去耦分组可放在所属器件附近或独立电源单元旁；标明归属器件与实际电源域。批量偏置/终端阵列有明确成员范围时可紧凑集中，决定滤波、增益、反馈等局部功能的网络仍就近展开。

## 3. 让接口映射可查

- 连接器可按针脚顺序、配对关系或库支持的功能 Bank 排列；选择最利于该页查线的方式，始终保留真实针号、器件身份及符号映射。
- 对密集接口，统一长度的短线与就近标签通常比横跨整页的多根实线更易查。接口之后的局部滤波、保护或端接如决定功能，应在其实现处清楚展开。
- 给 Bank 或重复组标明实际范围与去向；总线使用目标工具合法的成员、入口及连接方式。范围文字、粗线或并排画线本身不能证明成员连通。
- 当两端采用不同名称、基准索引或顺序时，保留逐成员对应关系；可增加清楚的映射注释或表，但表不能替代原生电气对象。不要把别名统一成一个新网名来美化。
- 保留已知的针一位置、观察面、配接/排线方向与装配条件，说明它们适用于哪个连接器；资料不足则标记待确认，不根据图形朝向猜测。

## 4. 区分信号路径与资源分配

- 局部信号或功率转换沿实际路径展开；公共供电、参考、地址与控制围绕所服务的组组织。共享控制不必沿主信号路径反复绕行。
- 多路或正负电源可在同页呈现来源、分支及后级关系，用已有名称和目的功能区分各输出；不能只靠相同电压值判断它们是同一网络。
- 共用供电不等于共用器件：局部去耦、偏置等保留各自归属。反过来，真正共享的参考源或控制资源也不为了视觉对称而复制。
- 参考网、隔离域与已有汇接点继续遵循连接基线；本节只决定表达，不增添 net-tie、地连接、保护件或计算设计参数。

## 5. 控制标注负担与视觉边界

- 读者首先看到功能标题、路径、位号/数值、针号及网络，再看到辅助字段和说明。项目统一哪些属性可见，隐藏显示不删除源数据。
- 长型号、封装/库字符串和重复字段不要与功能标注争夺空间。需要配接、装配或调试的信息仍保留在对应对象附近，或给出可靠的已有引用。
- DNP/NOP、默认跳线、互斥选件和模式说明是电路阅读信息，不当作生成日志移走。保留输入确认的状态，短注释放近对象；长推导、流程记录和完整资料摘录移至配套文档。
- 留白、对齐与标题已经能表达边界时可以无框；使用框时沿用全项目线型，框不能穿过文字或割裂支路。隔离或功能边界如需强调，保留明确名称，不用装饰色承担全部含义。
- 页名、图签与引用用已知信息填写；未知参数不补造。不要照搬参考图中的空占位符、任意大标题或忽大忽小的正文。

## 6. 用阅读任务验收

1. **找得到**：从总览或来源说明找到指定功能、通道范围及对应实现；对单页设计就在页内完成。
2. **看得懂**：在实现处追踪一条实际局部路径及相关支路，能区分级联、并行和共享资源。
3. **查得准**：从实现追到接口针号，核对真实名称、别名映射、索引与可用的视图说明；必要引用能定位到目标页或组。
4. **比得出差异**：重复组的首尾、边界和特例可辨；换页后相同语义的文字、符号、端口与标注仍用同一风格。

上述为可读性抽查。完整电气保真仍按器件属性和引脚到网络的成员关系比较；缺少原生工程时只报告图面证据与实际查看范围。
